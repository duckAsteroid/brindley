# Batch status backfill tool

## Goal

A `backfill_status` tool that records statuses for many initiatives in one call — each given explicitly or inferred from its prose (initiatives#7) — for files with no front-matter `status:` yet, applying the recording rule decided in initiatives#6. Adopting a 60-file folder becomes one call plus a review of what was written, instead of a `set_status` per file.

## Dependencies

_None._
